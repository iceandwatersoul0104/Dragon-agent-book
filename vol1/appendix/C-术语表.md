# 附录 C 术语表

本表收录全书反复出现的核心概念。术语以本书用法为准：同一英文概念在不同社区有不同中文译法时，以本书的译法为准；英文原文一栏保留社区通用拼写，便于按原文检索。

**「首现章」的编号规则**：全书分两卷，各有独立章号。第一卷的术语写「第 N 章」，第二卷引入的写「**第二卷** 第 N 章」——只写章号会指向两处。标注"多章出现"的概念表示它贯穿多章、没有唯一的首次引入点。
