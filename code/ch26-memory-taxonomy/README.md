# ch26-memory-taxonomy —— 工作 / 情景 / 语义 / 程序性 四类记忆的最小可实现

第 26 章《记忆分类学：工作、情景、语义与程序性记忆》的配套代码。

用一条真实的询价任务走完四类记忆的完整生命周期：写入、检索、冲突仲裁、流程升级、TTL 降权与显式遗忘。

## 目录

```
ch26-memory-taxonomy/
├── main.py      # 四类记忆的写入 / 读取 / 检索 / 遗忘实现
└── README.md    # 本文件
```

## 依赖

- Python 3.9 或更高
- **仅使用标准库**，不需要 `pip install` 任何东西
- `--live` 模式需要能访问 OpenAI 兼容的 chat/completions 接口（可选）

## 安装

没有安装步骤，克隆或下载后直接跑：

```bash
cd ch26-memory-taxonomy
python main.py
```

Windows 下如果控制台出现中文乱码，先设一下编码：

```powershell
$env:PYTHONIOENCODING="utf-8"; python main.py
```

## 运行命令

| 命令 | 作用 |
|---|---|
| `python main.py` | 跑完整演示：任务 → 写入 → 冲突 → 检索 → TTL → 遗忘 |
| `python main.py --query "预算多少"` | 只跑一次检索，不做写入流程 |
| `python main.py --live` | 用真实 LLM 做事实抽取（其余逻辑不变） |

## `--live` 所需环境变量

| 变量 | 必需 | 默认值 | 说明 |
|---|---|---|---|
| `OPENAI_API_KEY` | 是 | 无 | 未设置时会打印告警并自动回退到 mock |
| `OPENAI_BASE_URL` | 否 | `https://api.openai.com/v1` | 换成任意 OpenAI 兼容网关 |
| `OPENAI_MODEL` | 否 | `gpt-4o-mini` | 抽取用的模型 |

示例（PowerShell）：

```powershell
$env:OPENAI_API_KEY="sk-..."
$env:OPENAI_BASE_URL="https://api.openai.com/v1"
$env:OPENAI_MODEL="gpt-4o-mini"
python main.py --live
```

抽取失败（网络错误、返回不是合法 JSON）时会打印告警并自动回退到规则抽取，不会让整条链路挂掉。

## 输出怎么读

演示按六个阶段打印，每一段对应正文里的一个失效条件：

- **任务进行中（工作记忆）** —— 工作记忆是任务作用域的临时状态，任务结束就清理。这一段能看到它被主动清除。
- **任务完成 → 写入时刻** —— 事实按来源可信度写入语义记忆（用户陈述 > 工具返回 > 模型推断），每条带版本号。
- **冲突写入** —— 模型推断的写入被 **rejected**（不能污染语义记忆）；用户改口则 **updated**，旧值留版本。
- **程序性记忆** —— 流程连续成功三次才 `promoted` 为 `active`，前两次只是 `candidate`。
- **检索装配上下文** —— 四类记忆分别命中，按类别分区返回，并打印命中明细与分值。
- **TTL 到期** —— 情景记忆归档、语义记忆降权（"限时折扣"这类快变量到期就不该当作长期事实）。

## 四类记忆的关键实现点

| 类型 | 关键点 | 说明 |
|---|---|---|
| 工作记忆 | 作用域 + 生命周期 | 绑定 `task_id`，任务结束按作用域清理，不进长期存储 |
| 情景记忆 | 独立解释性 + 时效 | 记录"一次具体任务的经历"，脱离原始情境不成立；带 TTL，到期归档 |
| 语义记忆 | 来源可信度 + 版本号 | 只收可信来源的事实；冲突时高可信度覆盖并留版本；TTL 到期降权而非删除 |
| 程序性记忆 | 成功次数升级 | 候选 → 连续成功 N 次 → 激活；不装易变的 API 细节 |

## 局限（生产化时要换掉什么）

1. mock 模式的**事实抽取**是规则匹配，只覆盖预算、上线时间、偏好、身份四类，不是真正的语义抽取。
2. **相似度**是字符/词元级的朴素打分，不复刻真实 embedding 的语义泛化，也复刻不了向量库的召回盲区（详见第 27 章）。
3. 检索只按分数排序，**没有元数据过滤、摘要压缩与图谱仲裁**这三条工程手段（同样在第 27 章展开）。
4. 存储在内存里，**没有持久化、没有并发控制、没有多 Agent 共享状态的写入队列**（第 29 章）。
5. TTL 与升级阈值是硬编码常量，生产上应该由评测集扫出来，而不是拍。
