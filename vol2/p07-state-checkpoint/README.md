# 第 7 章 · 状态与检查点：让任务可回放、可恢复

本卷第七章把 Agent 的状态从"跑着的时候才有"变成"随时能拿出来看、能重跑、能接着跑"。

- 正文：[`state-checkpoint.md`](state-checkpoint.md)
- 配套工程产物：`dragon-agent/` 下的三个文件（见下）

## 本章给了什么

1. **`dragon_agent/state.py`（增量扩展）**——在第 6 章的状态层上加了三块东西：
   - **回放引擎**：`RecordingLLM`（录下模型响应）、`record_run()` / `replay()` / `compare_steps()`；
   - **已执行动作登记**：`ExecutedActions` + `restore_executed_actions()`；
   - 原有 `TaskState` / `Checkpoint` / `StateStore` 的公开接口**一个字没动**。
2. **`examples/state_replay_demo.py`**——实跑演示：录 → 重放 → 对比 → 崩溃恢复。
3. **`tests/test_replay.py`**——回放与恢复的单元测试：13 条断言。

第 6 章落盘的 `state.py` 与 `agent.py` **没有重写**，第 6 章的 38 条断言照常通过。

## 三个核心结论

### 1. 回放录的是模型响应，不是"重跑模型"

模型输出不可复现（温度、供应商侧变化、并发）。回放必须先把模型响应录下来，再用录下来的响应重跑——这样验证的是**控制流、工具与上下文**是否稳定，而不是比模型的随机性。

```python
class RecordingLLM:
    """包在模型客户端外面，把每次返回的响应录下来。

    这是回放的**唯一前提**：模型响应不可复现（温度、供应商侧变化、并发），
    所以必须先录。录下来之后，回放才有可能做到"同样的输入 → 同样的结果"。
    """
```

### 2. 快照与事件不是二选一

| | 快照 | 事件 |
| --- | --- | --- |
| 回答 | 现在是什么 | 怎么变成这样的 |
| 适合 | 崩溃恢复 | 复现问题、审计、对比两次运行 |

只有快照，你不知道"为什么"；只有事件，你得重放才知道"现在是什么"。`StateStore` 两个都做。

### 3. 跨进程的副作用去重靠"已执行动作登记"

工具层自己的幂等键缓存是**进程内**的，进程一崩就失效。`ExecutedActions` 把"哪些副作用已经发生过"单独记下来，落盘后装回工具层：

```
  重启后再执行：ok=False  error=charge 不可重放，幂等键 order-42 已用过，拒绝重复执行
  扣款函数实际被调用：0 次（第一次那次是在重启前的进程里）
```

## 怎么跑

```powershell
cd dragon-agent

# 1) 演示：离线跑通，退出码 0
python examples/state_replay_demo.py

# 2) 本章 + 第 6 章的测试：51 条断言
python -m unittest tests.test_replay tests.test_state tests.test_agent
```

不需要 API Key，不联网，不装任何第三方包。

### 实跑结果

| 场景 | 结果 | 退出码 |
| --- | --- | --- |
| `python examples/state_replay_demo.py` | 四段演示 + 自检全部通过 | 0 |
| `python -m unittest tests.test_replay tests.test_state tests.test_agent` | `Ran 51 tests` / `OK` | 0 |

演示里的关键输出：

- 回放结果与原运行**完全一致**（`与原运行一致：True`）；
- 把工具返回值改掉后，回放立刻指出 `第 1 步的 observation 不同`；
- 重启后装回登记，扣款函数**一次都没被调用**。

## 局限（这一章不等于可以上线）

- 回放是**进程内**的：录制件在内存里，落盘靠 `RunRecord.to_dict()` 自己写文件。没有跨机器的分布式回放，也没有多 worker 协调。
- 快照是**全量深拷贝**：历史长了以后每步一次拷贝会越来越贵，真到了那个规模要改增量或挪到专门存储。
- 已执行动作登记**没有过期策略**：一条登记该留多久，本章没定。
- 快照的**存储位置与加密**、并发写同一任务的锁，都还没做。
